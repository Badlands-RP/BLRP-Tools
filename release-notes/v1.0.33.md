# BLRP Tools v1.0.33

- Includes v1.0.32's NavMesh improvements: automatic target-build DLC discovery,
  custom resource dependency discovery, additional collision shapes and static
  fragment support, and clearer resource-conflict reporting.
- Preserves an explicit choice to disable automatic DLC discovery when reopening
  a project. Only untouched base-only selections from older versions are upgraded.
- Native collision, desktop and packaged launcher checks pass with Clinton Pawn
  on build 3095. Missing definitions, conflicting resources and source/baseline
  verification still block a complete export; FiveM movement testing is pending.
