# BLRP Tools v1.0.42

Loading Screen Tool now has a separate **Check + resize to 1920×1080** button. It checks every supported image in the linked project folder, center crops images of other sizes, and lists the files changed with their previous dimensions. Originals are saved under `.blrp-image-backups`.

The new **Remove UI Elements** tab lets you select numbered WebPs, choose a FiveM watermark or FPS corner area, or drag a custom area on the image preview. The tool fills the area with nearby image content. Review each result before exporting, especially on detailed backgrounds. Originals are saved under `.blrp-image-backups`.
