# BLRP Tools v1.0.36

- Clothing Utility v1.8.6 adds combined Gender, Component and Addon filters to
  QC results. For example, select Female + Hair + Addon 2, then sort the matches
  by polygons or another column. `CLEAR FILTERS` restores the full scanned list.
- Applying optimisation or LOD generation keeps the QC list, active filters,
  selected item, sorting and scroll position. Only the edited model is rechecked;
  resolved items remain visible as `OK` until the next QC scan.
- QC CSV exports include only the currently visible results.
- Verified with a Release build, Clothing Utility self-tests, a Hub launch
  self-test, and layout checks at the default and minimum window sizes.
