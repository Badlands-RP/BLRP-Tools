## Livery Studio: Simpler Vehicle Setup & Stock Liveries

- Set up carcols, carvariations and custom modkits together with one review and apply step.
- Automatically find the existing shared metadata files, with manual selection when needed.
- Repair identical duplicate modkits and clearly identify conflicting definitions.
- Use stock liveries directly from GTA as templates, without copying them into the server resource.
- Preview stock liveries and automatically select compatible templates for new artwork.
- Follow updated step-by-step setup guides in Help.
