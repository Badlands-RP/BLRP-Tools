## What's new

- Clothing Utility can now import textures for props, including hats and other `p_` clothing slots.
- Added optional texture optimisation during import: opaque textures become DXT1, while textures containing alpha automatically become DXT5.
- Prop imports now generate the correct collection-aware YTD filename and append the matching prop texture entry to the collection YMT.
- Import results report whether the output was preserved, encoded as DXT1, or encoded as DXT5.
- BLRP Tools Hub now shows the combined changelogs for every version between the installed build and the newest release, so skipped updates are fully explained before installation.

Texture optimisation is opt-in. Leave it unchecked to preserve the source texture format.
