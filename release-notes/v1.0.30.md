# BLRP Tools v1.0.30

- Fixes NavMesh area detection for interiors such as Mirror Park Cool Beans:
  readable YBN collision now sets the bounds in world coordinates instead of
  oversized interior metadata.
- The bounds reader now uses enabled GTA archives to resolve vanilla objects.
  **Game archives → Load base game** locates a Legacy installation and prepares
  base archives for previews without asserting target-build compatibility.
- Incomplete previews clearly show **Partial preview — resource build blocked**.
  Protected assets now name the affected model and explain the missing collision.
- Tested the desktop workflow against `hns_josecafe_mirror_park` and
  `hns_josecafe_base`. Protected furniture/door geometry and source verification
  still prevent a complete bake from the installed files alone; FiveM movement
  validation remains outstanding.
