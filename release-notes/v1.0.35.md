# BLRP Tools v1.0.35

- Asset Studio v1.4.0 adds a Stencil Creator for placing transparent spray
  artwork over a clean, bundled scroll background.
- Spray size and X/Y offsets update in the live preview, allowing tall details
  such as crowns to be kept within the paper before export.
- Stencil exports use the inventory naming convention automatically, for
  example `spray_ballas.png` becomes `stencil_ballas.webp`.
- Local files under `exports/` are now ignored by Git.
- Verified with a Release build, the Asset Studio self-test suite, and a visual
  Ballas stencil composition using the bundled blank scroll.
