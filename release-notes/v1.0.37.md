# BLRP Tools v1.0.37

- Clothing Utility v1.8.7 keeps imported props grouped by category and prop ID
  in the YMT. This prevents YMTEditor from restarting prop numbering when a
  category appears again later in the file, which can leave glasses, hats or
  earrings registered under duplicate IDs.
- Import verification checks existing props by anchor and ID, allowing the
  metadata to be grouped while still rejecting changes to unrelated entries.
- The clothing import self-test checks that the saved prop metadata stays
  grouped after a new prop is imported.
- Verified with the packaged Clothing Utility import regression test, native
  YMT save/reload checks and the Hub self-test. FiveM confirmation is pending.

Existing damaged YMTs require a separate metadata repair; this release does
not rewrite clothing repositories automatically.
