## Added

- Generate missing Medium and Low clothing LODs for one selected YDD at a time.
- Review the unchanged High model beside the generated Medium or Low model before applying it.
- Automatically select the matching `_a_uni` YTD when available and render textured LOD previews.
- Show the latest Git author, date, and short commit hash for the selected model when local history is available.
- Show High, Medium, and Low polygon counts in each model's QC details.
- Add a compact Git column to clothing results with the latest commit hash and full author/date/message details on hover.
- Choose Medium and Low polygon targets; defaults are 50% and 20%.
- Back up the original YDD before applying reviewed LODs.

## Safety and workflow

- High-detail geometry is never simplified or replaced.
- Existing Medium or Low LODs are preserved.
- When Medium already exists, Low is generated from it so Low cannot accidentally be denser than Medium.
- Cloth-simulated garments are detected and excluded from automatic LOD generation.
- Repository QC now lists over-20k models first, then orders remaining warnings by polygon count, keeping low-poly/no-LOD items lower priority.
- Clicking the Polys column now sorts by numeric polygon count instead of formatted text.

The included Clothing Utility version is 1.5.9.
