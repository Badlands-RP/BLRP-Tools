# BLRP Tools v1.0.31

- NavMesh now detects GTA V Legacy on opening, reuses a saved Livery Tool game
  folder, and remembers the game location, server build and results folder.
- The main workflow is **Add map resource → Generate preview → Review & export**.
  Previews fit the area automatically and find required interior definitions in
  neighboring resources, including `hns_josecafe_base` for Mirror Park Cool Beans.
- Coordinates, archive lists, pedestrian tuning and extra collision are under
  **Advanced settings**. Existing projects retain their saved area and sources.
- Warnings are grouped into plain-language categories with next steps and full
  details. Export explains what remains unresolved and requires a current preview.
- Updated the built-in Help / F1 guide to match the simpler workflow. Original
  navigation is saved to a new results subfolder without another folder dialog.
- Verified the desktop and packaged launcher against the installed Mirror Park
  cafe. Protected collision and source verification still block a complete cafe
  resource; this usability update does not establish FiveM movement acceptance.
