# BLRP Tools v1.0.41

Clothing Utility v1.9.1 fixes the Batch Previews window becoming difficult to switch to or interact with during an export.

- Replace one UI callback per texture with a latest-progress snapshot refreshed four times per second. Large cached exports no longer flood the window's message queue.
- Run the complete export and Backblaze upload workflows outside the UI thread, including catalogue indexing and upload preparation.
- Keep the owned export dialog attached to the main Clothing Utility window, without a second taskbar entry or its own minimise/maximise controls. Standalone batch-preview windows retain a taskbar entry.
- Display a clear cancelling state and check for cancellation while indexing custom textures. The current GTA archive operation may still need time to finish before cancellation completes.
- Add labels for the public preview URL and progress bar.

Verified with 100,000 rapid progress reports producing no UI callback posts, a real export with a running UI heartbeat and cancellation, and the existing preview/cache/Backblaze protocol self-checks.

Close the old Clothing Utility windows before installing this update. Completed preview files remain cached and can be reused on the next run.
