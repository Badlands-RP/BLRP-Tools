# BLRP Tools v1.0.34

- NavMesh can now build a test resource while bypassing prop, asset-conflict and
  source-verification warnings. In **Export**, enable **Allow warnings — build a
  test resource**, then click **Build test resource**. Original navigation is
  prepared automatically when needed.
- Missing collision is skipped and conflicting assets use the first selected
  copy. The output records all warnings in `BUILD-WARNINGS.txt` and identifies
  itself as a test resource. Turning bypass off restores strict checks.
- Test builds retain existing navigation markers and special-route polygons
  inside the edit area, with warnings for runtime review. Original special routes
  may overlap the new patch. Invalid references, changed hashes, wrong baseline
  builds, missing tiles and conflicting output tile names still stop a build.
- Fixed composition of original polygons with concave corners and preservation
  of existing zero-length vanilla edges outside the edit.
- Verified Clinton Pawn on build 3095 through native save/reload and the desktop
  workflow. The generated test resource still needs FiveM movement testing.
