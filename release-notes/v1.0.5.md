## What's new

- Clothing Utility blacklist choices now include current Panel businesses, common vRP service groups, and restriction values already present in the selected EUP repository.
- Added common service presets including LEO, LSFD, LSPD, Sheriff, SAHP, FIB, NYSP, Dispatch, Ranger, DOC, and DOJ.
- Added multi-select blacklist assignment. Selecting multiple entries produces the server's existing pipe-separated access rule, such as `LEO|LSFD`.

The included Clothing Utility version is 1.5.4.
