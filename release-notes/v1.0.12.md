## Clothing Utility

- Preview a selected clothing result directly in the built-in textured 3D viewer, including repository QC results.
- Automatically select the matching clothing YTD for the quick preview.
- Add an optional `AGGRESSIVE FALLBACK` mode for Medium and Low LOD generation when protected mesh borders prevent the normal simplifier from reaching its target.
- Keep conservative border-preserving LOD generation available by unticking the aggressive option.
- Stop applying a global wait cursor during background scans, fixing the persistent spinning cursor over the results grid.

## Safety

- High-detail geometry remains unchanged in both LOD modes.
- Generated candidates still require side-by-side manual review before they can be applied.
- Existing LODs remain preserved and original YDDs are backed up before applying changes.

The included Clothing Utility version is 1.6.0.
