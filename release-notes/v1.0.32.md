# BLRP Tools v1.0.32

- NavMesh previews now find local DLC using the selected server build's update
  archive, including hash-matched FiveM cache copies. Explicit source selections
  remain available, and newer installed updates are not substituted.
- Required custom prop and interior resources are found across the containing
  resources tree using their actual YTYP definitions, including selected entity
  sets. Clinton Pawn now discovers its `props_Addon` dependency automatically.
- Added spheres, capsules, cylinders and collision-box primitives, plus static
  fragment physics whose rest-pose transforms can be verified.
- Conflicting resource assets now appear as a separate warning category and allow
  an inspection preview. They still block a complete resource build.
- Updated Help / F1. Native collision tests and the desktop Clinton Pawn workflow
  pass on build 3095. Missing definitions, conflicting assets and archive/baseline
  verification still require review; FiveM movement testing remains outstanding.
