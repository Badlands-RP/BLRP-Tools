## Sign Batch Builder

- Add a redesigned Sign Batch Builder inside BLRP Livery Tool.
- Preview and validate numbered source-to-output mappings before writing files.
- Accept PNG and DDS sign textures, generating DXT5/BC3 textures with mipmaps when conversion is needed.
- Compile the bundled sign blank directly into ready-to-use YFT files through CodeWalker.
- Export matching YFT and DDS pairs to one clean output folder without overwriting existing work.
- Allow an optional custom YFT XML template and replacement token for advanced batches.
