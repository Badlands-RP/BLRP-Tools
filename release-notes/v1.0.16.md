## Clothing Utility 1.7.2 safety fixes

- LOD optimisation now writes real reduced face/index counts that agree with OpenIV, not just smaller vertex buffers.
- Saved candidates are rejected before apply/export if their polygon metadata, indices, shaders, or texture bindings are inconsistent.
- Clothing and prop imports verify that existing YMT entries remain unchanged before any files are written.
- Optional DXT compression now preserves uncommon source texture formats instead of failing partway through a batch.
- Added `EXTERNAL YDD...` to optimise a pre-import YDD and export it with automatically detected sibling YTD files, without changing a repository or YMT.
