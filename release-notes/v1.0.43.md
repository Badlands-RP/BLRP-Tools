# BLRP Tools v1.0.43

Loading Screen Tool now keeps its dark background and readable text on both tabs.

The UI removal tab uses a small brush or corner mask and local inpainting. Preview Removal changes nothing on disk. Compare the result with Show Original, then press Save Changes to apply it. The mask size is limited to prevent broad accidental edits. Originals are backed up with their original file extension before saving.

Export to the active server folder remains a separate step after Save Changes.
