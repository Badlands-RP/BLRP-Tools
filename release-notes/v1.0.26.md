# BLRP Tools v1.0.26

- Clothing Utility: search blacklist groups by partial name, including in Combine;
  checked groups and the active restriction remain selected while searching.
- Blacklist export: filter the clothing list by gender, component, ID, scope or
  filename. ZIP ALL still exports the entire selected blacklist group.
- Model and texture pickers remember separate folders across restarts. A removed
  folder falls back to the normal starting location.
- Prop model and texture imports preserve all existing component and prop YMT
  metadata; the supplied nine-texture straw hat now imports cleanly.
- Property Mapper's GTA 3D preview now enables the newest installed DLC before
  loading the exported map in BadWalker.
- grzy preview: all 12 base clothing component slots, including JBIB, HAND, TEEF,
  ACCS, TASK and DECL. Use -1 for no base model. Save as default stores each
  gender separately and existing defaults are retained for the original slots.
- Includes the Durty save-version-5 project converter and Classic display mode.
  Conversion reports unsupported options and changed drawable numbering.
- Packaging now compiles the clothing preview viewer from source.
