# BLRP Tools v1.0.40

Clothing Utility v1.9.0 adds **Batch Previews** with an **Update + Upload** action for the new clothing store.

- Generate transparent WebP previews outside FiveM for Rockstar and custom clothing, both genders and all registered textures. Automatic framing focuses on the item; unchanged renders are reused.
- Correct prop orientation, front/back accessory views, empty-slot placeholders and emissive materials. Reviewed facial hair from Masks and Bags is shown on a neutral reference head.
- Save export folders, target server build, image size and blacklist options. The default target is build 3095 and images default to 256 pixels.
- Upload new or changed previews to Backblaze. Identical images share one content-addressed file, matching remote files are skipped, and uploads include checksum verification, retries and long-lived cache headers.
- Keep application keys out of export settings and game resources. Enter them in the masked upload fields or supply the local `BLRP_B2_KEY_ID` and `BLRP_B2_APPLICATION_KEY` environment variables.
- Export stable collection-based catalogue metadata so the store can resolve the correct image without relying on global clothing-number offsets.

## Setup

Open **Clothing Utility → Batch Previews**, select the EUP source and store preview output folders, and enable Backblaze upload. Use a public preview bucket and an application key restricted to that bucket with Read and Write access and the `clothing-previews/` prefix. Listing all bucket names is not required.

After a successful upload, copy the displayed public URL into the server config using `setr clothing_preview_url "PUBLIC_URL"`. Deploy the generated catalogue metadata with the updated clothing store. The image library stays out of Git and the FiveM resource download.

Offline build, GUI, browser and upload-protocol checks passed. Live bucket upload and FiveM verification are separate checks. Missing or blank source textures are reported by the exporter and use the store's fallback icons; this release does not replace those source assets.
